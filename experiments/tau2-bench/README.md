# tau2 benchmark

This directory contains the tau2 benchmark source and data used for the paper's airline and retail evaluations. The benchmark is from [Sierra Research](https://github.com/sierra-research/tau2-bench); local changes are described in [PATCHES.md](PATCHES.md).

Use the [FORGE tau2 experiment guide](../tau2/README.md) for setup, paired runs, and saved-result analysis. The upstream Python package is `tau2`; FORGE's adapter is the separate `forge_tau2` package.
